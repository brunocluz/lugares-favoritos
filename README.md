# 🌍 Meus Lugares Preferidos

## 📖 Sobre o projeto

Este projeto foi desenvolvido como atividade da disciplina de Git e GitHub. O objetivo é criar um site colaborativo onde cada integrante apresenta seus lugares favoritos.
